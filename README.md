# Total Incorporações — protótipo de site

MVP comercial para apresentar internamente: Home + página de campanha do Recanto do Horizonte.

## Como rodar

```bash
npm install
npm run dev
```

Abra o endereço local que o Vite imprimir. Build: `npm run build`.

## O que está no ar

- `/` — quem é a Total, quatro Recantos, bloco institucional
- `/empreendimentos/recanto-do-horizonte` — destino de campanha com fatos públicos + WhatsApp

Contatos vêm do Instagram oficial (`@totalincorporacoes`). Validar internamente antes de qualquer publicação no domínio do cliente.

## Fora deste protótipo

CMS, formulário, mapa, plantas, SEO técnico, páginas Sobre/Contato.
